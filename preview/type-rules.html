Usage rules
Scale & contrast
  • —Minimum 1.5× jump from heading to body
  • —Display only if clear hierarchy below
  • —Never Montserrat below 16px (no body)
  • —Negative letter-spacing only above 24px
Weight & colour
  • —Montserrat 700 reserved for display and h1
  • —Maximum two weights per screen
  • —Helvetica never bold for body
  • —Labels always Montserrat 600 uppercase
